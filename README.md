Busy Bunny downloads

Busy Bunny is a to-do app for Windows, made for screen readers and braille displays first. It is easy to start, hard to get overwhelmed by, and forgiving when you fall behind.

This page holds the finished app and what is new in each version. Busy Bunny checks here for updates by itself.

To install: open Releases, pick the newest one, and download BusyBunny-arm64.exe for an ARM laptop like a Surface with Snapdragon, or BusyBunny-x64.exe for other Windows PCs. Put it somewhere of your own, like your Documents folder, and open it. Nothing else needs installing. If Windows SmartScreen says it does not recognise the app, choose More info, then Run anyway.

To check a download: each release has a file called sha256sums.txt with a checksum for each program file.

To report a problem or ask for a feature: open an issue on this page. Issues here are public, so leave out anything private, like the names of your tasks.

What you may do with the app: see LICENSE.txt.

What the app does with your information: see PRIVACY.txt. In short, your tasks stay on your own computer.
